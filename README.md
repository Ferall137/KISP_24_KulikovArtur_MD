# Конспект по мобильной разработке: Экосистема Expo

> **Expo CLI** — это комплексный инструмент автоматизации (аналог `dotnet CLI` + MSBuild), который позволяет инициализировать, разрабатывать, компилировать и запускать кроссплатформенные приложения на JavaScript/TypeScript для Android, iOS и Web из единой кодовой базы.

---

## 1. Create a project (Создание проекта)

Для создания нового кроссплатформенного приложения используется встроенный менеджер пакетов Node.js и утилита генерации шаблонов.

* **Команда инициализации:**
  ```bash
  npx create-expo-app@latest
  ```
* **Особенность:** Команда разворачивает готовый шаблон проекта, настраивает структуру папок, базовые зависимости и конфигурационные файлы.

---

## 2. Set up your environment (Настройка окружения)

Чтобы запускать и тестировать код нативно, необходимо подготовить рабочую среду компьютера под целевые платформы.

* **Для локальной разработки:** 
  * Требуется установленная платформа **Node.js** (LTS-версия).
  * Для Android: **Android Studio** и настроенный Android Virtual Device (Эмулятор).
  * Для iOS (только на macOS): **Xcode** и Simulator.
* **Альтернатива (Expo Go):** Можно не ставить тяжелые Android SDK и Xcode локально, а установить приложение *Expo Go* из App Store / Google Play на свой личный смартфон. Компьютер и телефон должны быть в одной Wi-Fi сети.

---

## 3. Start developing (Начало разработки)

Запуск локального сервера разработки и сборки бандла.

* **Команда запуска:**
  ```bash
  npx expo start
  ```
* **Интерфейс управления:** В терминале запустится Dev Server и сгенерирует **QR-код**.
* **Способы открытия приложения:**
  * Сканирование QR-кода через камеру (iOS) или приложение Expo Go (Android) для тестирования на физическом устройстве.
  * Нажатие клавиши `a` в терминале — для автоматического открытия на эмуляторе Android.
  * Нажатие клавиши `i` в терминале — для открытия на симуляторе iOS.
  * Нажатие клавиши `w` — для запуска веб-версии в браузере.

---

## 4. Next steps (Следующие шаги)

Развитие проекта и управление конфигурацией.

* **Архитектура проекта:** Вся конфигурация нативных модулей описывается декларативно в файле `app.json` (аналог `.csproj` файла в C#). Expo сама сгенерирует нативный код на основе этого JSON-файла.
* **Добавление библиотек:** Вместо стандартного `npm install` в Expo строго рекомендуется использовать внутреннюю команду для автоматического подбора совместимых версий:
  ```bash
  npx expo install имя_библиотеки
  ```

---

## 5. Tools for development (Инструменты разработки)

Инструменты, ускоряющие отладку и написание кода.

* **Fast Refresh:** Изменения в коде (например, в JSX-компонентах) мгновенно отображаются на экране телефона/эмулятора без перезапуска приложения и потери состояния экрана.
* **Dev Menu (Меню разработчика):** Вызывается встряхиванием телефона или нажатием `Ctrl + M` (в эмуляторе). Позволяет перезагрузить JS-бандл, включить дебаггер или посмотреть логи производительности.
* **Expo Snack:** Облачная интерактивная песочница (подобие *.NET Fiddle*), позволяющая писать и запускать код React Native прямо в браузере без локальной установки окружения.

---

## 6. Navigation (Навигация в приложении)

Организация переходов между экранами.

* **Expo Router:** Современный стандарт навигации в Expo, использующий **файловую маршрутизацию** (аналог концепций из веб-фреймворков вроде Next.js или ASP.NET Core Blazor/Pages).
* **Принцип работы:** Структура папок внутри директории `app/` автоматически определяет пути экранов:
  * Файл `app/index.js` станет главным (стартовым) экраном приложения.
  * Файл `app/settings.js` будет доступен по пути маршрута `/settings`.
* Поддерживает нативные вкладки (Tabs), стек переходов (Stack) и всплывающие меню (Drawer).
