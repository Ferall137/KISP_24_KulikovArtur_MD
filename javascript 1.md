# Конспект: Введение в JavaScript
---

## 1. Что такое JavaScript?

**JavaScript (JS)** — язык программирования со своей спецификацией (**ECMAScript**), изначально созданный для того, чтобы «сделать веб-страницы живыми».

*   **Скрипты** — программы на JS. Они встраиваются в HTML и выполняются как простой текст (не требуют предварительной компиляции).
*   **Движок (виртуальная машина)** — специальная программа, выполняющая код JS.
    *   *V8* — Chrome, Opera, Edge.
    *   *SpiderMonkey* — Firefox.
    *   *JavaScriptCore / Nitro* — Safari.
*   **Алгоритм работы движка:**
    1. Чтение («парсинг») текста скрипта.
    2. Преобразование («компиляция») в машинный код.
    3. Выполнение и динамическая оптимизация на лету.

---

### 2. Возможности JavaScript в браузере

В браузерной среде JS сфокусирован на работе с веб-страницами, взаимодействии с пользователем и сервером:
*   **Манипуляции с DOM/CSS:** добавление, изменение и удаление HTML-тегов, управление стилями.
*   **Интерактивность:** реакция на действия пользователя (клики, движения мыши, нажатия клавиш).
*   **Сетевые запросы:** отправка и получение данных с серверов (технологии AJAX и COMET), скачивание/загрузка файлов.
*   **Работа с данными:** получение и установка куки (cookies), использование локального хранилища (`localStorage`).

---

### 3. Ограничения безопасности (Чего JS НЕ может в браузере)

Для защиты личных данных пользователей возможности JS в браузере строго ограничены:
*   **Нет прямого доступа к ОС:** JS не может произвольно читать/записывать файлы на жёстком диске или запускать системные программы без явных действий пользователя (например, drag-and-drop или выбор файла через `<input>`).
*   **Ограничение работы с медиа:** доступ к камере или микрофону требует обязательного ручного разрешения пользователя.
*   **Политика одинакового источника (Same Origin Policy):** вкладки и окна с разных сайтов (доменов/портов) изолированы друг от друга и не могут воровать чужие данные или токены авторизации.
*   **Ограничение на кросс-доменные запросы:** отправка запросов на другие домены ограничена и требует явного согласия удалённого сервера (настройка HTTP-заголовков/CORS).

---

### 4. Главные особенности JavaScript

Уникальность JS заключается в сочетании трех ключевых факторов:
1.  **Полная интеграция** с HTML и CSS.
2.  **Простота решения** базовых задач.
3.  **Универсальная поддержка** всеми основными браузерами (включен по умолчанию).

---

### 5. Языки «над» JavaScript (Транспиляторы)

Для расширения возможностей синтаксиса используются языки, которые **транспилируются** (конвертируются) в чистый JS перед запуском:
*   **TypeScript** — добавляет строгую типизацию для разработки крупных систем (от Microsoft).
*   **CoffeeScript** — синтаксический сахар для лаконичного и чистого кода (популярен среди Ruby-разработчиков).
*   **Flow** — альтернативный подход к типизации (от Meta/Facebook).
*   **Dart** — язык со своим движком вне браузера, используемый также для мобильных приложений, но требующий транспиляции для веба (от Google).
*   **Brython** — транспилирует Python в JavaScript, позволяя писать клиентскую часть на Python.

---


## 2. Справочники и спецификации

При постоянной работе с JavaScript учебника становится недостаточно. Необходимы авторитетные источники информации.

* **Справочник MDN (Mozilla)** — главный ежедневный инструмент разработчика для проверки методов объектов, функций и синтаксиса.
* **Таблицы совместимости** — ресурсы для проверки поддержки возможностей языка в разных браузерах:
  * [caniuse.com](https://caniuse.com) — таблицы поддержки по конкретным фичам.
  * [kangax.github.io/compat-table](https://github.io) — интерактивная таблица соответствия движков стандартам.

Инструменты для написания кода делятся на два основных типа, и разработчики часто комбинируют их в работе.

### IDE (Интегрированная среда разработки)
Мощные программы для работы на уровне **всего проекта**. Обеспечивают автодополнение по всему коду, интеграцию с Git, системами тестирования и терминалом.

Быстрые и простые инструменты для оперативного редактирования отдельных файлов. При установке плагинов границы между ними и IDE могут размываться.

## 4. Консоль разработчика

По умолчанию браузер скрывает ошибки в коде от обычных пользователей. Для их отлова используются встроенные инструменты разработки (**DevTools**).

### Горячие клавиши для открытия консоли:
* **Windows / Linux (все браузеры):** `F12`.
* **Chrome (Mac):** `Cmd + Opt + J`.
* **Safari (Mac):** `Cmd + Opt + C` *(требуется предварительно включить «Меню разработки» в Продвинутых настройках браузера)*.

### Возможности консоли:
1. **Просмотр ошибок** — выводятся красным цветом с указанием конкретного файла и строки кода, где произошел сбой.
2. **Командная строка** — синий символ `>` позволяет выполнять JavaScript прямо "на лету".
3. **Многострочный ввод** — чтобы перенести строку без выполнения кода, используйте комбинацию `Shift + Enter`.



# Основы JavaScript: Операторы, преобразования типов и ветвление

Конспект по материалам базового раздела JavaScript (learn.javascript.ru).

---

## 1. Преобразование типов

Чаще всего операторы автоматически приводят значения к нужной форме (например, `alert` — к строке, математика — к числам). Также существуют функции для явного приведения.

### Строковое преобразование (`String()`)
Происходит очевидным образом: `true` становится `"true"`, `null` -> `"null"`, `undefined` -> `"undefined"`.

### Численное преобразование (`Number()`)
Происходит в математических функциях и выражениях.

| Исходное значение | Результат преобразования в число |
| :--- | :--- |
| `undefined` | `NaN` |
| `null` | `0` |
| `true` / `false` | `1` / `0` |
| `string` | Пробелы по краям обрезаются. Пустая строка становится `0`. Если строка содержит не только цифры — `NaN`. |

### Логическое преобразование (`Boolean()`)
* **`false`** возвращают интуитивно «пустые» значения: `0`, `""` (пустая строка), `null`, `undefined`, `NaN`.
* **`true`** возвращают все остальные значения.
* ⚠️ **Важно:** Строка с нулем `"0"` и строка с пробелом `" "` — это **`true`** (любая непустая строка).

---

## 2. Базовые операторы и математика

### Терминология
* **Операнд (аргумент):** то, к чему применяется оператор. В `5 * 2` операнды — `5` и `2`.
* **Унарный оператор:** применяется к одному операнду (например, унарный минус: `x = -x`).
* **Бинарный оператор:** применяется к двум операндам (`y - x`).

### Особенности бинарного плюса `+`
Если хотя бы один операнд является **строкой**, бинарный плюс выполняет **конкатенацию (склеивание)** и приводит второй операнд к строке:
```javascript
alert('1' + 2); // "12"
alert(2 + 2 + '1'); // "41" (вычисляется слева направо: 4 + '1')
```
*Все остальные математические операторы (`-`, `*`, `/`, `%`, `**`) работают исключительно с числами и всегда приводят строки к числу.*

### Унарный плюс `+`
Примененный к не-числу, унарный плюс работает как быстрый аналог `Number()`:
```javascript
alert(+"2" + +"3"); // 5 (бинарный плюс сложит числа, так как унарные перевели строки)
```

### Инкремент `++` и декремент `--`
Увеличивают или уменьшают переменную на `1`. Применяются **только к переменным**.
* **Префиксная форма (`++counter`):** сначала изменяет переменную, затем возвращает её **новое** значение.
* **Постфиксная форма (`counter++`):** изменяет переменную, но возвращает её **старое** значение (до изменения).

### Полезные операторы
* **Взятие остатка `%`:** `5 % 2` возвращает `1` (остаток от деления).
* **Возведение в степень `**`:** `2 ** 3` вернет `8` (\(2^3\)).
* **Оператор «запятая» `,`:** выполняет несколько выражений, но возвращает результат только последнего: `let a = (1 + 2, 3 + 4); // a = 7`. Имеет самый низкий приоритет.

## 3. Операторы сравнения

Все операторы сравнения возвращают логическое значение: `true` или `false`.

### Сравнение строк
Строки сравниваются посимвольно в **лексикографическом (алфавитном) порядке** на основе кодировки **Unicode**:
* Сравниваются первые символы, при равенстве — вторые, и т.д.
* Строчные буквы всегда **больше** заглавных (`'a' > 'A'`), так как их код в Unicode находится дальше.
* Более длинная строка при прочих равных считается большей (`'Сонный' > 'Сон'`).

### Сравнение разных типов и строгое равенство
* При сравнении разных типов (через `>`, `<`, `==`) значения приводятся к **числу**.
* **Проблема нестрогого равенства `==`:** оно не отличает `0` от `false` или `""` от `false` (`0 == false` вернет `true`).
* **Решение — Строгое равенство `===`:** проверяет равенство **без приведения типов**. Разные типы сразу дают `false` (`0 === false` -> `false`).

### Специфика `null` и `undefined`
1. При строгом равенстве `===` они не равны друг другу (`null === undefined` -> `false`).
2. При нестрогом равенстве `==` они **равны друг другу**, но не равны ничему другому (`null == undefined` -> `true`, но `null == 0` -> `false`).
3. В операторах сравнения (`>`, `<`, `>=`, `<=`) `null` становится `0`, а `undefined` превращается в `NaN`. Из-за этого возникает парадокс:
   ```javascript
   alert(null > 0);  // false
   alert(null == 0); // false (по правилу №2)
   alert(null >= 0); // true  (null приводится к 0, а 0 >= 0)
   ```
*Рекомендация: Избегайте сравнений типа `>`, `<` с переменными, которые могут содержать `null` или `undefined`.*

## 4. Условное ветвление: `if`, `?`

### Инструкция `if` и блок `else`
Вычисляет условие в скобках, приводя результат к логическому типу (`Boolean`). 
Рекомендуется всегда ставить фигурные скобки `{}` для блоков кода, даже если инструкция всего одна.

Блок `else if` позволяет проверить несколько альтернативных условий последовательно.

### Тернарный оператор `?`
Единственный оператор с тремя аргументами. Используется для компактного возврата значения на основании условия:
```javascript
let result = (условие) ? значение_если_true : значение_если_false;
```
*Не используйте тернарный оператор вместо полноценного `if` ради выполнения действий, так как горизонтальный код читается хуже вертикального.*

---

## 5. Логические операторы

JavaScript поддерживает «сокращенное вычисление»: операнды вычисляются слева направо до тех пор, пока результат не станет очевиден.

### Директива ИЛИ `||` (находит первое истинное значение)
Возвращает **первое правдивое (`truthy`)** значение, на котором остановилось вычисление. Если все ложны — возвращает последнее.
```javascript
alert( null || 0 || "Успех" || false ); // "Успех"
alert( undefined || null || 0 );        // 0 (все ложны, вернулось последнее)
```
* **Логическое присваивание `||=`:** присваивает значение переменной только в том случае, если текущее значение переменной является ложным (`falsy`): `a ||= b` (эквивалентно `a || (a = b)`).

### Директива И `&&` (находит первое ложное значение)
Возвращает **первое ложное (`falsy`)** значение, на котором остановилось вычисление. Если все истинны — возвращает последнее.
```javascript
alert( 1 && 5 && null && 3 ); // null
alert( 1 && 2 && 3 );        // 3 (все истинны, вернулось последнее)
```
* **Приоритет:** Оператор `&&` имеет более высокий приоритет, чем `||` (выполняется раньше).
* **Логическое присваивание `&&=`:** присваивает значение только если переменная истинна (`truthy`): `a &&= b`.

### Логическое НЕ `!`
Приводит операнд к логическому типу и инвертирует его. Двойное НЕ `!!` используется как короткий способ явного приведения к булевому типу (`!!null` -> `false`). Имеет наивысший приоритет среди логических операторов.

---

## 6. Операторы нулевого слияния и присваивания: `??`, `??=`

Оператор нулевого слияния `??` считает значение «определенным», если оно **не** является `null` или `undefined`.

### Главное отличие `??` от `||`
* `||` возвращает первое **истинное** значение (игнорирует `0`, `""`, `false`, `null`, `undefined`).
* `??` возвращает первое **определенное** значение (игнорирует только `null` и `undefined`).

Это критично, когда `0` или пустая строка являются валидными данными проекта:
```javascript
let height = 0;
alert(height || 100); // 100 (0 — это falsy, сработало значение по умолчанию)
alert(height ?? 100); // 0   (0 определен, значение по умолчанию не нужно)
```

### Важные ограничения `??`
1. Из-за соображений безопасности **запрещено** использовать `??` вместе с `&&` или `||` без явных круглых скобок:
   ```javascript
   let x = 1 && 2 ?? 3; // Синтаксическая ошибка!
   let x = (1 && 2) ?? 3; // Работает корректно (x = 2)
   ```
2. Оператор имеет низкий приоритет (равен `3`), поэтому в математических выражениях левую и правую части с `??` нужно брать в скобки.

### Логическое присваивание `??=`
Присваивает значение правой части переменной только в том случае, если переменная сейчас равна `null` или `undefined`:
```javascript
let userAge = null;
userAge ??= 18; // userAge станет равен 18
```

## 1. Циклы `while` и `for`

Циклы используются для многократного повторения одного и того же участка кода (одно выполнение тела называется **итерацией**).

### Типы циклов
1. **`while (условие)`** — проверка условия происходит *до* итерации. Если условие изначально ложно, код не выполнится ни разу.
2. **`do { ... } while (условие)`** — проверка условия происходит *после* итерации. Тело цикла гарантированно выполнится **хотя бы один раз**.
3. **`for (начало; условие; шаг)`** — самый популярный цикл. 
   * Любую часть `for` можно пропустить (например, `for (; i < 3;)`), но точки с запятой `;` внутри круглых скобок обязательны.
   * Бесконечный цикл: `for (;;)` или `while (true)`.

### Управление циклом
* **`break`** — полностью прекращает выполнение цикла и выводит поток кода за его пределы.
* **`continue`** — «облегченная версия» `break`. Немедленно прекращает текущую итерацию и принудительно переходит к следующей (к проверке условия).
* ⚠️ **Ограничение:** `break` и `continue` нельзя использовать справа от тернарного оператора `?`.
* **Метки (`labelName:`)** — идентификатор с двоеточием, ставящийся перед циклом. Нужен для того, чтобы `break/continue` могли выйти из вложенных (многоуровневых) циклов сразу во внешний поток (`break labelName;`).

---

## 2. Конструкция "switch"

Конструкция `switch` заменяет собой множественные проверки `if..else` и сравнивает выражение сразу с несколькими вариантами.

```javascript
switch(x) {
  case 'value1': // if (x === 'value1')
    ...
    [break]
  default:
    ...
}
```

### Важные нюансы
* **Строгое равенство:** Сравнение значений в `case` всегда идет по принципу строгого равенства `===` (учитывая типы данных).
* 🔴 **Пропуск `break`:** Если внутри `case` отсутствует директива `break`, выполнение кода пойдет лавиной вниз по следующим блокам `case`, полностью **игнорируя их условия**, пока не встретит первый `break` или конец `switch`.
* **Группировка:** `case` можно группировать, если они должны выполнять один и тот же код:
  ```javascript
  case 3:
  case 5:
    alert('Неправильно!');
    break;
  ```

---

## 3. Функции в JavaScript

Функции — это основные строительные блоки программы для избавления от дублирования кода.

### Общие правила
* **Область видимости:** 
  * Переменные, объявленные внутри функции, являются **локальными** (снаружи они не видны).
  * Функция имеет полный доступ к **внешним (глобальным)** переменным и может их изменять, если внутри функции нет одноименной локальной переменной (локальная перекрывает внешнюю).
* **Параметры и Аргументы:** Параметр — это переменная в объявлении функции. Аргумент — значение, передаваемое при её вызове.
* **Значения по умолчанию:** Если аргумент не передан, параметр инициализируется как `undefined`. Дефолтное значение задается через оператор равенства в заголовке: `function show(text = "пусто")`.
* **Возврат значения (`return`):** Функция останавливается в момент вызова `return`. Если в функции нет `return` или он пустой, она возвращает **`undefined`**.
* ⚠️ **Важно:** Интерпретатор автоматически ставит точку с запятой после `return`, поэтому нельзя переносить возвращаемое выражение на следующую строку без открывающей круглой скобки: `return (\n выражение \n)`.

---

## 4. Три способа создания функций

JavaScript позволяет объявлять функции тремя принципиально разными методами:

### A. Function Declaration (Объявление Функции)
Классический синтаксис в основном потоке кода.
```javascript
function sum(a, b) { return a + b; }
```
* 🔥 **Главная фишка:** Такие функции движок JS создает на этапе инициализации, поэтому их **можно вызывать до того, как они описаны в коде**.
* Имеют блочную область видимости в строгом режиме (видны только внутри `{}`).

### B. Function Expression (Функциональное Выражение)
Создание функции внутри другого выражения (например, присваивание переменной).
```javascript
let sum = function(a, b) { return a + b; }; // Нужна точка с запятой в конце!
```
* Функция создается только тогда, когда поток выполнения **доходит до этой строки**. Вызвать ее раньше инициализации нельзя.
* Функции без имени, передаваемые внутрь других функций (например, для отложенного вызова), называются **анонимными функциями** или **колбэками (callbacks)**.

### C. Стрелочные функции (Arrow Functions)
Сверхкомпактный современный синтаксис.
* **Однострочные (без фигурных скобок):** вычисляют выражение справа и **автоматически возвращают** его результат (писать `return` не нужно).
  ```javascript
  let double = n => n * 2; // Если параметр один, круглые скобки вокруг него можно опустить
  let sayHi = () => alert("Привет"); // Без параметров скобки обязательны
  ```
* **Многострочные (с фигурными скобками):** скобки требуют обязательного явного написания директивы **`return`** внутри тела.
  ```javascript
  let calc = (a, b) => { let res = a + b; return res; };
  ```

---

## 5. Итоговая шпаргалка по разделу «Основы»

* **Разделители:** Инструкции разделяются `;`. Перенос строки работает как авто-разделитель, но имеет опасные исключения (например, перед квадратными скобками `[`).
* **Режим работы:** `"use strict";` в первой строчке кода включает современный стандарт выполнения (в классах и модулях включен автоматически).
* **Переменные:** Динамически типизированы. Доступно 8 типов: `number`, `bigint`, `string`, `boolean`, `null`, `undefined`, `object`, `symbol`.
* **Модальные окна:** `alert()` (вывод), `prompt()` (ввод, возвращает строку или `null`), `confirm()` (вопрос Да/Нет, возвращает `true/false`).
* **Равенство:** `==` сравнивает с приведением типов к числу (`null` равен только `undefined`). `===` — строгое равенство без приведения типов.





















# Основы JavaScript: Базовый синтаксис и взаимодействие

## 1. Привет, мир! (Подключение скриптов)

Для интеграции JavaScript-кода в HTML используется тег `<script>`.

### Способы подключения
1. **Внутренний код:** код пишется прямо внутри тегов.
   ```html
   <script>
     alert('Привет, мир!');
   </script>
   ```
2. **Внешний файл:** подключение через атрибут `src`.
   ```html
   <script src="script.js"></script>
   <script src="./js/alert.js"></script>
   ```

> ⚠️ **Важно:** Если у тега `<script>` установлен атрибут `src`, то внутреннее содержимое тега **игнорируется**. Нельзя совмещать оба способа в одном теге:
> ```html
> <!-- ТАК НЕ РАБОТАЕТ -->
> <script src="file.js">alert(1);</script> 
> ```

* **Плюс внешних файлов:** Браузер кеширует их, что экономит трафик и ускоряет загрузку страниц.
* Устаревшие атрибуты `type="text/javascript"` и `language="javascript"` в современном HTML **не требуются**.

---

## 2. Структура кода

### Инструкции и точка с запятой
* Код состоит из инструкций (команд), разделяемых точкой с запятой `;`.
* **Автоматическая вставка:** Перенос строки часто интерпретируется как «неявная» точка с запятой. 

> 🔴 **Опасность автоматической вставки:** Браузер не всегда правильно распознает конец инструкции. Например, перед квадратными скобками `[` точка с запятой автоматически **не ставится**:
> ```javascript
> // Этот код вызовет ошибку, так как выполнится как единая строка alert('Hello')[1, 2]...
> alert('Hello')
> [1, 2].forEach(alert);
> ```
> **Рекомендация:** Всегда явно ставьте точку с запятой в конце каждой инструкции.

### Комментарии (игнорируются движком)
* Однострочные: `// текст комментария` (горячие клавиши `Ctrl + /`).
* Многострочные: `/* текст */` (горячие клавиши `Ctrl + Shift + /`). Вложенные многострочные комментарии `/* /* ... */ */` **запрещены**.

---

## 3. Строгий режим — "use strict"

Директива `"use strict";` включает современный режим работы движка, активируя изменения стандарта ES5 (2009 год) и запрещая устаревшие опасные практики.

* Должна находиться в **самой первой строчке** скрипта (выше могут быть только комментарии). Если написать её ниже `alert()`, строгий режим не включится.
* Действует на весь файл (или внутри конкретной функции).
* **Отменить строгий режим нельзя** (команды вроде "no use strict" не существует).
* **Современный JS:** При использовании JS-модулей (`type="module"`) и классов строгий режим включен **автоматически**.

---

## 4. Переменные и константы

Переменная — это именованное хранилище данных («коробка»).

### Объявление (`let`, `const`, `var`)
* `let` — современный способ объявления переменной. Значение можно менять.
* `const` — объявление константы (неизменяемой переменной). Попытка перезаписи вызовет ошибку.
* `var` — устаревший способ (имеет свои специфические отличия).

### Константы в верхнем регистре
Используйте `UPPER_CASE` только для жестко закодированных значений, известных **до запуска** скрипта:
```javascript
const COLOR_RED = "#F00"; // Верхний регистр — значение известно заранее
const pageLoadTime = 124; // Нижний регистр — вычисляется в процессе работы
```

### Правила именования переменных
1. Разрешены только буквы, цифры, а также символы `\$` и `_`.
2. Первым символом **не может** быть цифра.
3. Регистр букв имеет значение (`apple` и `APPLE` — разные переменные).
4. Запрещено использовать зарезервированные слова (`let`, `class`, `function` и др.).
5. Рекомендуется использовать стиль **camelCase** (например, `currentUserName`).

## 5. Восемь типов данных

JavaScript является **динамически типизированным** языком: тип данных привязан к значению, а не к переменной.

### Примитивные типы (7 типов)
1. **`number` (число):** Целые числа и числа с плавающей точкой. Включает специальные значения:
   * `Infinity` (математическая бесконечность, например `1 / 0`).
   * `NaN` (вычислительная ошибка, например `"строка" / 2`). Любая операция с `NaN` возвращает `NaN`.
2. **`bigint`:** Для целых чисел произвольной длины (числа за пределами диапазона `±(253-1)`). Пишется с буквой `n` на конце: `12345678n`.
3. **`string` (строка):** Нет отдельного символьного типа (как `char`). Бывает трех видов:
   * Одинарные `'...'` и двойные `"..."` кавычки (одинаковые по смыслу).
   * Обратные кавычки `` `...` `` — позволяют встраивать выражения через `${...}`:
     ```javascript
     alert(`Результат: ${1 + 2}`); // Результат: 3
     ```
4. **`boolean` (логический):** Принимает только `true` (истина) или `false` (ложь).
5. **`null`:** Специальный тип, означающий «пусто», «ничего» или «значение неизвестно».
6. **`undefined`:** Специальный тип, означающий «значение не присвоено» (автоматически у объявленных, но не инициализированных переменных).
7. **`symbol`:** Используется для создания уникальных идентификаторов в объектах.

### Сложный тип (1 тип)
8. **`object` (объект):** Используется для коллекций данных и сложных структур (в отличие от примитивов, хранящих одно значение).

### Оператор `typeof`
Возвращает строку с именем типа аргумента. Имеет две формы: `typeof x` или `typeof(x)`.
* `typeof undefined` // `"undefined"`
* `typeof 10n` // `"bigint"`
* `typeof alert` // `"function"` *(формально функции — это объекты, но typeof выделяет их для удобства)*
* `typeof null` // `"object"` *(**официально признанная ошибка в языке**, на самом деле null — это не объект!)*

---

## 6. Взаимодействие с пользователем

Все три метода вызывают **модальные окна**: они блокируют интерфейс страницы, пока пользователь не закроет окно. Их внешний вид и положение нельзя изменить настройками кода.

| Метод | Что делает / Параметры | Возвращаемое значение |
| :--- | :--- | :--- |
| **`alert(text)`** | Показывает модальное окно с сообщением. | Ничего (`undefined`). |
| **`prompt(title, [default])`** | Выводит окно с вопросом и полем ввода. `default` — начальное значение. | Строку (введенный текст) или `null`, если нажата кнопка «Отмена»/Esc. |
| **`confirm(question)`** | Показывает окно с вопросом и кнопками OK и Отмена. | `true`, если нажата кнопка OK; `false` в остальных случаях. |

* **Важно для prompt:** Всегда указывайте второй аргумент (хотя бы пустую строку `''`), иначе Internet Explorer подставит в поле ввода текст `"undefined"`.
