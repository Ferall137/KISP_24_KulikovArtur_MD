# Конспект: Введение в JavaScript
---

## 1. Что такое JavaScript?

**JavaScript (JS)** — язык программирования со своей спецификацией (**ECMAScript**), изначально созданный для того, чтобы «сделать веб-страницы живыми».

*   **Скрипты** — программы на JS. Они встраиваются в HTML и выполняются как простой текст (не требуют предварительной компиляции).
*   **Движок (виртуальная машина)** — специальная программа, выполняющая код JS.
    *   *V8* — Chrome, Opera, Edge.
    *   *SpiderMonkey* — Firefox.
    *   *JavaScriptCore / Nitro* — Safari.
*   **Алгоритм работы движка:**
    1. Чтение («парсинг») текста скрипта.
    2. Преобразование («компиляция») в машинный код.
    3. Выполнение и динамическая оптимизация на лету.

---

### 2. Возможности JavaScript в браузере

В браузерной среде JS сфокусирован на работе с веб-страницами, взаимодействии с пользователем и сервером:
*   **Манипуляции с DOM/CSS:** добавление, изменение и удаление HTML-тегов, управление стилями.
*   **Интерактивность:** реакция на действия пользователя (клики, движения мыши, нажатия клавиш).
*   **Сетевые запросы:** отправка и получение данных с серверов (технологии AJAX и COMET), скачивание/загрузка файлов.
*   **Работа с данными:** получение и установка куки (cookies), использование локального хранилища (`localStorage`).

---

### 3. Ограничения безопасности (Чего JS НЕ может в браузере)

Для защиты личных данных пользователей возможности JS в браузере строго ограничены:
*   **Нет прямого доступа к ОС:** JS не может произвольно читать/записывать файлы на жёстком диске или запускать системные программы без явных действий пользователя (например, drag-and-drop или выбор файла через `<input>`).
*   **Ограничение работы с медиа:** доступ к камере или микрофону требует обязательного ручного разрешения пользователя.
*   **Политика одинакового источника (Same Origin Policy):** вкладки и окна с разных сайтов (доменов/портов) изолированы друг от друга и не могут воровать чужие данные или токены авторизации.
*   **Ограничение на кросс-доменные запросы:** отправка запросов на другие домены ограничена и требует явного согласия удалённого сервера (настройка HTTP-заголовков/CORS).

---

### 4. Главные особенности JavaScript

Уникальность JS заключается в сочетании трех ключевых факторов:
1.  **Полная интеграция** с HTML и CSS.
2.  **Простота решения** базовых задач.
3.  **Универсальная поддержка** всеми основными браузерами (включен по умолчанию).

---

### 5. Языки «над» JavaScript (Транспиляторы)

Для расширения возможностей синтаксиса используются языки, которые **транспилируются** (конвертируются) в чистый JS перед запуском:
*   **TypeScript** — добавляет строгую типизацию для разработки крупных систем (от Microsoft).
*   **CoffeeScript** — синтаксический сахар для лаконичного и чистого кода (популярен среди Ruby-разработчиков).
*   **Flow** — альтернативный подход к типизации (от Meta/Facebook).
*   **Dart** — язык со своим движком вне браузера, используемый также для мобильных приложений, но требующий транспиляции для веба (от Google).
*   **Brython** — транспилирует Python в JavaScript, позволяя писать клиентскую часть на Python.

## 2. Справочники и спецификации

При постоянной работе с JavaScript учебника становится недостаточно. Необходимы авторитетные источники информации.

* **Спецификация ECMA-262** — самый глубокий, детальный и официальный документ, определяющий язык. Обновляется ежегодно. Черновики доступны на [tc39.es](https://tc39.es), а новые предложения (Stage 3 proposals) — на GitHub.
* **Справочник MDN (Mozilla)** — главный ежедневный инструмент разработчика для проверки методов объектов, функций и синтаксиса.
* **Таблицы совместимости** — ресурсы для проверки поддержки возможностей языка в разных браузерах:
  * [caniuse.com](https://caniuse.com) — таблицы поддержки по конкретным фичам.
  * [kangax.github.io/compat-table](https://github.io) — интерактивная таблица соответствия движков стандартам.

## 3. Редакторы кода

Инструменты для написания кода делятся на два основных типа, и разработчики часто комбинируют их в работе.

### IDE (Интегрированная среда разработки)
Мощные программы для работы на уровне **всего проекта**. Обеспечивают автодополнение по всему коду, интеграцию с Git, системами тестирования и терминалом.
* **Visual Studio Code** — бесплатная, кроссплатформенная и самая популярная среда.
* **WebStorm** — мощная среда от JetBrains (бесплатна для некоммерческого использования).
* **Visual Studio** — тяжелая платная IDE для Windows (в основном под .NET, есть версия Community).

### «Легкие» редакторы
Быстрые и простые инструменты для оперативного редактирования отдельных файлов. При установке плагинов границы между ними и IDE могут размываться.
* **Sublime Text** — кроссплатформенный, условно-бесплатный.
* **Notepad++** — бесплатный редактор исключительно для Windows.
* **Vim / Emacs** — консольные редакторы, требующие специальных навыков.

## 4. Консоль разработчика

По умолчанию браузер скрывает ошибки в коде от обычных пользователей. Для их отлова используются встроенные инструменты разработки (**DevTools**).

### Горячие клавиши для открытия консоли:
* **Windows / Linux (все браузеры):** `F12`.
* **Chrome (Mac):** `Cmd + Opt + J`.
* **Safari (Mac):** `Cmd + Opt + C` *(требуется предварительно включить «Меню разработки» в Продвинутых настройках браузера)*.

### Возможности консоли:
1. **Просмотр ошибок** — выводятся красным цветом с указанием конкретного файла и строки кода, где произошел сбой.
2. **Командная строка** — синий символ `>` позволяет выполнять JavaScript прямо "на лету".
3. **Многострочный ввод** — чтобы перенести строку без выполнения кода, используйте комбинацию `Shift + Enter`.
