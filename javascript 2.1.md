# Основы JavaScript: Операторы, преобразования типов и ветвление

Конспект по материалам базового раздела JavaScript (learn.javascript.ru).

---

## 1. Преобразование типов

Чаще всего операторы автоматически приводят значения к нужной форме (например, `alert` — к строке, математика — к числам). Также существуют функции для явного приведения.

### Строковое преобразование (`String()`)
Происходит очевидным образом: `true` становится `"true"`, `null` -> `"null"`, `undefined` -> `"undefined"`.

### Численное преобразование (`Number()`)
Происходит в математических функциях и выражениях.

| Исходное значение | Результат преобразования в число |
| :--- | :--- |
| `undefined` | `NaN` |
| `null` | `0` |
| `true` / `false` | `1` / `0` |
| `string` | Пробелы по краям обрезаются. Пустая строка становится `0`. Если строка содержит не только цифры — `NaN`. |

### Логическое преобразование (`Boolean()`)
* **`false`** возвращают интуитивно «пустые» значения: `0`, `""` (пустая строка), `null`, `undefined`, `NaN`.
* **`true`** возвращают все остальные значения.
* ⚠️ **Важно:** Строка с нулем `"0"` и строка с пробелом `" "` — это **`true`** (любая непустая строка).

## 2. Базовые операторы и математика

### Терминология
* **Операнд (аргумент):** то, к чему применяется оператор. В `5 * 2` операнды — `5` и `2`.
* **Унарный оператор:** применяется к одному операнду (например, унарный минус: `x = -x`).
* **Бинарный оператор:** применяется к двум операндам (`y - x`).

### Особенности бинарного плюса `+`
Если хотя бы один операнд является **строкой**, бинарный плюс выполняет **конкатенацию (склеивание)** и приводит второй операнд к строке:
```javascript
alert('1' + 2); // "12"
alert(2 + 2 + '1'); // "41" (вычисляется слева направо: 4 + '1')
```
*Все остальные математические операторы (`-`, `*`, `/`, `%`, `**`) работают исключительно с числами и всегда приводят строки к числу.*

### Унарный плюс `+`
Примененный к не-числу, унарный плюс работает как быстрый аналог `Number()`:
```javascript
alert(+"2" + +"3"); // 5 (бинарный плюс сложит числа, так как унарные перевели строки)
```

### Инкремент `++` и декремент `--`
Увеличивают или уменьшают переменную на `1`. Применяются **только к переменным**.
* **Префиксная форма (`++counter`):** сначала изменяет переменную, затем возвращает её **новое** значение.
* **Постфиксная форма (`counter++`):** изменяет переменную, но возвращает её **старое** значение (до изменения).

### Полезные операторы
* **Взятие остатка `%`:** `5 % 2` возвращает `1` (остаток от деления).
* **Возведение в степень `**`:** `2 ** 3` вернет `8` (\(2^3\)).
* **Оператор «запятая» `,`:** выполняет несколько выражений, но возвращает результат только последнего: `let a = (1 + 2, 3 + 4); // a = 7`. Имеет самый низкий приоритет.

## 3. Операторы сравнения

Все операторы сравнения возвращают логическое значение: `true` или `false`.

### Сравнение строк
Строки сравниваются посимвольно в **лексикографическом (алфавитном) порядке** на основе кодировки **Unicode**:
* Сравниваются первые символы, при равенстве — вторые, и т.д.
* Строчные буквы всегда **больше** заглавных (`'a' > 'A'`), так как их код в Unicode находится дальше.
* Более длинная строка при прочих равных считается большей (`'Сонный' > 'Сон'`).

### Сравнение разных типов и строгое равенство
* При сравнении разных типов (через `>`, `<`, `==`) значения приводятся к **числу**.
* **Проблема нестрогого равенства `==`:** оно не отличает `0` от `false` или `""` от `false` (`0 == false` вернет `true`).
* **Решение — Строгое равенство `===`:** проверяет равенство **без приведения типов**. Разные типы сразу дают `false` (`0 === false` -> `false`).

### Специфика `null` и `undefined`
1. При строгом равенстве `===` они не равны друг другу (`null === undefined` -> `false`).
2. При нестрогом равенстве `==` они **равны друг другу**, но не равны ничему другому (`null == undefined` -> `true`, но `null == 0` -> `false`).
3. В операторах сравнения (`>`, `<`, `>=`, `<=`) `null` становится `0`, а `undefined` превращается в `NaN`. Из-за этого возникает парадокс:
   ```javascript
   alert(null > 0);  // false
   alert(null == 0); // false (по правилу №2)
   alert(null >= 0); // true  (null приводится к 0, а 0 >= 0)
   ```
*Рекомендация: Избегайте сравнений типа `>`, `<` с переменными, которые могут содержать `null` или `undefined`.*

## 4. Условное ветвление: `if`, `?`

### Инструкция `if` и блок `else`
Вычисляет условие в скобках, приводя результат к логическому типу (`Boolean`). 
Рекомендуется всегда ставить фигурные скобки `{}` для блоков кода, даже если инструкция всего одна.

Блок `else if` позволяет проверить несколько альтернативных условий последовательно.

### Тернарный оператор `?`
Единственный оператор с тремя аргументами. Используется для компактного возврата значения на основании условия:
```javascript
let result = (условие) ? значение_если_true : значение_если_false;
```
*Не используйте тернарный оператор вместо полноценного `if` ради выполнения действий, так как горизонтальный код читается хуже вертикального.*

## 5. Логические операторы

JavaScript поддерживает «сокращенное вычисление»: операнды вычисляются слева направо до тех пор, пока результат не станет очевиден.

### Директива ИЛИ `||` (находит первое истинное значение)
Возвращает **первое правдивое (`truthy`)** значение, на котором остановилось вычисление. Если все ложны — возвращает последнее.
```javascript
alert( null || 0 || "Успех" || false ); // "Успех"
alert( undefined || null || 0 );        // 0 (все ложны, вернулось последнее)
```
* **Логическое присваивание `||=`:** присваивает значение переменной только в том случае, если текущее значение переменной является ложным (`falsy`): `a ||= b` (эквивалентно `a || (a = b)`).

### Директива И `&&` (находит первое ложное значение)
Возвращает **первое ложное (`falsy`)** значение, на котором остановилось вычисление. Если все истинны — возвращает последнее.
```javascript
alert( 1 && 5 && null && 3 ); // null
alert( 1 && 2 && 3 );        // 3 (все истинны, вернулось последнее)
```
* **Приоритет:** Оператор `&&` имеет более высокий приоритет, чем `||` (выполняется раньше).
* **Логическое присваивание `&&=`:** присваивает значение только если переменная истинна (`truthy`): `a &&= b`.

### Логическое НЕ `!`
Приводит операнд к логическому типу и инвертирует его. Двойное НЕ `!!` используется как короткий способ явного приведения к булевому типу (`!!null` -> `false`). Имеет наивысший приоритет среди логических операторов.

## 6. Операторы нулевого слияния и присваивания: `??`, `??=`

Оператор нулевого слияния `??` считает значение «определенным», если оно **не** является `null` или `undefined`.

### Главное отличие `??` от `||`
* `||` возвращает первое **истинное** значение (игнорирует `0`, `""`, `false`, `null`, `undefined`).
* `??` возвращает первое **определенное** значение (игнорирует только `null` и `undefined`).

Это критично, когда `0` или пустая строка являются валидными данными проекта:
```javascript
let height = 0;
alert(height || 100); // 100 (0 — это falsy, сработало значение по умолчанию)
alert(height ?? 100); // 0   (0 определен, значение по умолчанию не нужно)
```

### Важные ограничения `??`
1. Из-за соображений безопасности **запрещено** использовать `??` вместе с `&&` или `||` без явных круглых скобок:
   ```javascript
   let x = 1 && 2 ?? 3; // Синтаксическая ошибка!
   let x = (1 && 2) ?? 3; // Работает корректно (x = 2)
   ```
2. Оператор имеет низкий приоритет (равен `3`), поэтому в математических выражениях левую и правую части с `??` нужно брать в скобки.

### Логическое присваивание `??=`
Присваивает значение правой части переменной только в том случае, если переменная сейчас равна `null` или `undefined`:
```javascript
let userAge = null;
userAge ??= 18; // userAge станет равен 18
```
